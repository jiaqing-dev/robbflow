# RobbFlow 产品定义

> **RobbFlow — Open Source Engineering Operating System**
>
> 面向现代企业的开源研发协作与流程自动化平台。

## 不是什么

- 不是禅道 / Redmine 的换皮
- 不是「中国版 Jira」
- 不是把 Issue / Sprint / Kanban 当成产品边界

## 是什么

把战略到反馈的研发闭环变成可运行的对象图：

```text
战略 → OKR → 产品 → 需求 → 项目 → 任务 → 代码 → CI/CD → 测试 → 发布 → 线上问题 → 数据 → 下一轮需求
```

叠加：组织、权限、知识、**文档中枢（引用飞书/钉钉/网盘，不做 Wiki）**、AI Agent、自动化、数据分析。

面向中小企业：同一套工作项跑需求、缺陷、发布与简易工单；审批走状态机节点 + 飞书/钉钉通知，**接入 OA 而不自建 OA**。

## 中国企业差异化

原生：飞书 / 企业微信 / 钉钉、LDAP / OIDC / AD、国产数据库、私有化、内网、信创。

## 核心理念

```text
Project → Work → Workflow → Automation → AI
```
